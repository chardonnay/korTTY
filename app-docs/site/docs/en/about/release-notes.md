# Release notes

What changed in the current release. The version this guide was built for is shown in the footer.

## v2.26.3

### Connections

- Quick Connect and the Connection Manager support Telnet profiles for network terminals and legacy console servers. The tab identifies Telnet as unencrypted, and administrators can disable it in enterprise policy.

### Terminal

- Renamed **Monitor for Silence** to **Monitor for Inactivity** in the terminal tab menu, command palette, and notification settings across all supported languages.
- Exporting selected log lines now keeps the format options open until you confirm, so you can convert selected JSON entries to XML before choosing where to save them.

### Dependencies

- Updated Monaco Editor to 0.58.0, Guava to 33.8.0-jre, Logback to 1.6.8, and zstd-jni to 1.5.7-28.
