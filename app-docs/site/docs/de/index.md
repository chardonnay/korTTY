# korTTY-Anleitung

<p class="kt-tagline">
Die vollständige Referenz für korTTY – ein moderner, plattformübergreifender JavaFX-SSH-Client
mit Tab-Terminals, SFTP-Tools, einem Hintergrund-Job-Scheduler und einem Snippet
Management, Terminal-Effekt-Plugins und OpenAI-kompatible KI-Unterstützung.
Alle Funktionen, Einstellungen und Tools werden ausführlich erklärt.
</p>

<span class="kt-badge">Drücken Sie F1 in korTTY, um diese Anleitung zu öffnen</span>

Diese Anleitung ist in korTTY gebündelt (**Hilfe → Anleitung**, Verknüpfung ++f1++)

automatisch mit dem Code synchronisiert. Die korTTY-Version diese Anleitungs
gebaut wurde, wird in der Fußzeile angezeigt.
