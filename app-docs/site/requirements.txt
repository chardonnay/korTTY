# Pinned toolchain for the korTTY documentation site and EN-to-DE generation.
# Installed into the throwaway .venv-docs venv (see build.gradle.kts setupDocsVenv).
# The `search` plugin ships inside MkDocs itself — no extra deps needed.
#
# FULLY pinned, transitive dependencies included, because the built guide is COMMITTED under
# src/main/resources/guide and docs-autocommit fails on main when a rebuild differs from it
# ("src/main/resources/guide is stale"). Pinning only the direct dependencies left the
# HTML-producing packages floating: Pygments renders every highlighted code block, and 2.21
# escapes `"` inside code as `&quot;`, so pages nobody had touched (teamwork,
# building-packages, enterprise-policy) differed on every rebuild once CI resolved a different
# version than the machine that last staged the bundle. Markdown, pymdown-extensions and the
# Jinja2 template stack shape that output just as directly.
#
# mkdocs-material is deliberately absent. It reaches end of life on 2026-11-05 and is already
# incompatible with the in-development MkDocs 2.0; the guide is built with mkdocs-dracula-theme
# instead. Removing it drops babel, backrefs, colorama, mkdocs-material-extensions, paginate
# and pillow with it — verified by rebuilding both languages against a Material-free venv and
# diffing: all 407 files of the committed bundle come out byte for byte identical.
#
# To upgrade: bump the pin(s), run `./gradlew stageGuideIntoResources`, and commit the
# regenerated bundle together with the change — never separately.
