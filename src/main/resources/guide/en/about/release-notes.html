Release notes¶

What changed in the current release. The version this guide was built for is shown in the footer.

v2.21.0¶

SFTP Manager¶

  • Compare and synchronize folders — Compare reads both folders, the local one and the one on the server, with all subfolders, counts what is only on one side, newer or different, and colours the rows. To the server and To this computer copy what is missing or newer, keep modification times, and can delete what exists only on the target. See Comparing and synchronizing folders.
  • File comparison with AI questions and a new file from both — select two files, two in one panel or one in each, also a local one against one on the server, and click Compare to see them side by side. With the AI features on, Ask AI explains where they differ, what the differences do or what could be improved, for example in scripts and configuration files, and New file has the AI write a third file from both, which you can save on the server or on this computer or keep in the Snippet Manager. Two folders on the same side can be compared as well. See Comparing two files.
  • Active panel, path bar and status line — the panel you clicked or typed in last is framed in the accent colour; each panel has its own row of buttons under its list, with Upload and Download facing each other across the divider. Each panel shows its path as clickable folders (Cmd+L or Ctrl+L to type one) and a line under the list with the number of entries, the selection and its size. Rows are compact in every design. See Active panel and Path bar and status line.
  • Hidden files and sort order — an eye button beside each panel's path, or Cmd+Shift+. (Ctrl+Shift+. on Windows and Linux), shows or hides dot files and folders (and Windows hidden files); each panel remembers its choice. Hidden folders come first, then hidden files, folders and files, in every column. See Hidden files and Sort order.
  • Permission checkboxes — Set Owner/Permissions shows the mode as checkboxes for owner, group and others next to the octal field and keeps both in step. On the local side the user, the group and Apply recursively to directories now take effect. See Permissions.
  • User and group names, folder sizes — servers that send owners only as numbers, such as OpenSSH, now show user and group names, looked up on the server in the background. Calculate size in the server's right-click menu measures folders with du, and the size estimate in the archive dialog now includes the selected folders. See Owner and group names and Folder sizes.
  • Archive dialog says what it archives — the computer, the folder, the number of folders and files and their names. The server's archive tools are looked up in the background, so a server that runs no commands no longer freezes the window. See Creating archives.

Settings and AI Manager¶

  • Search in the settings — a search line at the top of Global Settings finds a setting on any tab as you type. Choosing a result opens its tab, scrolls to the setting, colours it and focuses its control. See Searching the settings.
  • Manual for each tab and section — Manual for this page in the settings navigation bar opens the built-in manual at the page for the current tab, and the section headers on the Logging, Resources, Security and Privacy tabs link to the section that explains them. The Logging tab now says that it concerns korTTY's own application log, not terminal session logs. See Manual for each tab.
  • Automatic encrypted backup — Settings → Backup → Automatic backup creates a backup on a schedule (daily, weekly or monthly) into a folder you choose, always encrypted, and catches up a backup that was missed while korTTY was closed. A status line says when the last one ran and when the next is due; an organization policy can lock the setting. See Automatic backup.
  • Translation profiles — Settings → Translation keeps several translation profiles, one of them the default, with a setup assistant for a new one. Translate now shows an estimate before it starts and can be paused and cancelled. See Translation profiles and Translate now.
  • Theme preview — the Themes tab shows the theme list in a narrow column and previews the selected theme on a sample terminal screen with a directory listing, git status, compiler messages, all sixteen ANSI colours and the theme's cursor. See Theme preview.
  • AI settings in the AI Manager — the AI tab of Global Settings moved into the AI Manager's new General tab, which holds the options that belong to no profile: features and safety, the terminal agent, defaults and internet access. See General tab.
  • Profile editor in sections — the Profiles tab keeps the profile name and Use as default profile at the top and groups the fields into Connection, Model & capabilities, Limits & timeouts and Budget & usage. Only the rows of the selected connection mode are shown, the request timeout that applies to every profile heads the Limits & timeouts section, and Test AI Connection, Delete and Save sit under the editor. See AI Manager. Test AI Connection shows its result in a coloured bar under the profile name instead of only in the status line.
  • Profile setup wizard — a sidebar shows the stages and the choices already made, a Quick start finds LM Studio, Ollama (on this computer, on the hosts you enter under Other computers on the network, and on the hosts of existing profiles) and installed command-line tools and offers one-click profiles, connection types and providers are cards, reasoning sits under Advanced, and the last step runs the test by itself and shows a summary with Change links. See AI Profile Setup Wizard.
  • Local AI in sections — the Local AI tab splits into Profile roles, Local runtime and Hugging Face. See Text, coding, translation, and embedding roles.

JobScheduler¶

  • Job dependencies — a job can depend on other jobs and either keep its own schedule but only run when every predecessor's last run succeeded (Condition), or start automatically once all predecessors have succeeded (Chain), optionally only counting recent successes. Cycles are refused, the job list shows a Depends on column, and deleting a job that others depend on warns first. Run with successors runs a job and everything below it in dependency order, and Disable chain switches a job and all its dependents off or on at once. See Job Dependencies.
  • Dependency diagram — draws the job dependencies as a Mermaid flowchart colored by each job's last result, vertical or horizontal, in light or dark mode, with SVG/PNG export. See Dependency Diagram.

Fixes and maintenance¶

  • Reconnected tunnels get their ports back — after a reconnect, a remote (-R) tunnel could fail with Address already in use because korTTY asked for the port again before the server had released it. korTTY now waits for the server to release a remote forward before it hands the tunnel over. See SSH Tunnels.
  • Snippet AI processing beside the analysis — the progress of applying a full code analysis sits in an AI processing column at the snippet editor's right edge, sized to its checklist, and can be moved into the analysis panel. See Applying the selected improvements.
  • JobScheduler time windows show their times — the Window from and Window until fields no longer cut the selected time off.
